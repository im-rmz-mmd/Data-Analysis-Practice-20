# 🧸 Power BI Retail Dashboard — Toy Sales Analysis

A one-page dashboard built with Power BI that analyzes toy sales across multiple stores.

## 🔍 Project Overview
Data cleaning, relationship modeling, and visual storytelling — all in one!

### 🔧 Data Sources
- Sales
- Products
- Inventory
- Stores
- Calendar

### 📊 Key Insights
- **Top-selling product categories**
- **Monthly revenue trends**
- **Sales by store and city**
- **Comparison of stock vs sales**

### 💡 What I Learned
Power BI is more than just charts — it’s about connecting the dots.  
This dashboard shows how DAX, good layout, and modeling make data speak.
